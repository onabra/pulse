# Chat Platform

یک پلتفرم چت مدرن برای ارتباط امن و سریع بین کاربران، با پشتیبانی از چت **خصوصی، عمومی، گروهی و کانالی**.

این پروژه با هدف ارائه‌ی یک تجربه‌ی پیام‌رسانی انعطاف‌پذیر طراحی شده و از **رمزنگاری سرتاسری (End-to-End Encryption)** برای محافظت از محتوای پیام‌ها استفاده می‌کند؛ به این معنا که فقط فرستنده و گیرنده‌ی پیام قادر به مشاهده‌ی محتوای آن هستند.

## قابلیت‌ها
- چت خصوصی بین دو کاربر
- چت عمومی
- ساخت و مدیریت گروه‌ها
- ساخت و مدیریت کانال‌ها
- ارسال و دریافت پیام به‌صورت دوطرفه و real-time
- رمزنگاری سرتاسری برای امنیت پیام‌ها
- احراز هویت و مدیریت کاربران
- معماری مبتنی بر API

## هدف پروژه
هدف این پروژه ایجاد یک سیستم پیام‌رسان امن، مقیاس‌پذیر و قابل توسعه است که بتوان از آن به‌عنوان پایه‌ای برای یک اپلیکیشن چت دسکتاپ یا تحت وب استفاده کرد.

## تکنولوژی‌ها

- Spring Boot
- Spring Security
- WebSocket
- JPA
